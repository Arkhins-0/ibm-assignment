# Simple Interest Calculator

A simple bash script to calculate simple interest given the principal amount, annual rate of interest, and time period in years.

## Input

* **p**: Principal amount
* **r**: Annual rate of interest
* **t**: Time period in years

## Output

* **simple interest** = $p \times t \times r / 100$

---

## How to Run

### 1. Clone this repository:

   git clone [https://github.com/Arkhins-0/ibm-assignment.git](https://github.com/Arkhins-0/ibm-assignment.git)
   cd ibm-assignment
Make the script executable:


chmod +x simple-interest.sh
Run the script:

./simple-interest.sh
Follow the prompts to enter:

Principal amount

Rate of interest per year

Time period in years

Example Usage
Plaintext
Enter the principal:
1000
Enter rate of interest per year:
5
Enter time period in years:
2
The simple interest is: 
100
